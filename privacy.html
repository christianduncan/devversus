Privacy Policy

Effective: November 17, 2026

"Dev vs. uploader" is a private tool used only by the owner of the Dev vs. YouTube channel to manage that channel. It is not offered to the public.

What it accesses

Through the YouTube API Services, with the channel owner's permission, the tool uploads videos, sets video and channel metadata (titles, descriptions, thumbnails, banner), and reads analytics for the owner's own channel.

What it stores

An OAuth access token is stored only on the channel owner's computer. No data is collected from viewers or any other users. No data is sold, shared, or transferred to third parties.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, which also deletes the tool's ability to use the stored token.
